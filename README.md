# 나만의 영어회화 필수단어 학습 사이트

기획안(`나만의_영어회화_필수단어_학습사이트_기획안_1.md`, 2026-08-30) 기반 개인용 정적 웹앱.
서버·로그인 없이 동작하며, 학습 진도는 브라우저 `localStorage`에 저장됩니다.

## 배포된 링크

https://claude.ai/code/artifact/33e4a924-f424-47c9-97c7-d8ae7e817003 (비공개)

휴대폰에서는 이 링크로 학습합니다. `node tools/build.js` 후 같은 파일 경로로 다시 배포하면
같은 링크가 갱신됩니다.

### 진도 저장 방식

Artifact 뷰어에서는 브라우저 저장소(localStorage)가 방문 사이에 유지되지 않는다.
그래서 진도는 `artifact` 런타임 capability로 아티팩트에 딸린 **`data/progress.json`**
파일에 저장한다 (파일 단위 publish라 페이지는 그대로 두고 데이터만 갱신되며, 저장한
화면은 리로드되지 않는다). 결과적으로 휴대폰과 Mac이 같은 진도를 공유한다.

- 저장 시점: Day 완료 / 완료 취소 / 진도 초기화 / 백업 복원 / 하루 목표 단어 수 변경
  (카드 넘김 위치는 버전이 과하게 늘지 않도록 기기 저장소에만 둔다)
- 두 기기 상태가 다르면 **더 많이 진행한 쪽**을 채택하고 학습 기록은 날짜별로 합친다
- 로컬(`./start.sh`)에서는 이 런타임이 없으므로 localStorage만 사용한다 — 정상 동작이다
- 배포에 `capabilities: {artifact: {}}` 선언이 필요하다. 선언을 빠뜨리면 동기화가 꺼진다

> ⚠️ 페이지를 다시 배포하면 `data/progress.json`이 초기화될 수 있다.
> 재배포 전에 **설정 → 데이터 백업**의 문자열을 복사해 두고, 배포 후 복원할 것.

## 실행

```bash
./start.sh
```

브라우저에서 http://localhost:4321 접속. (`dist/index.html`은 더블클릭만으로도 열립니다.)

- 하루 15개 × 주 6일 → 총 200 Day (설정에서 10~30개로 변경 가능, Day 구분이 자동 재계산됨)

- 주 6일차(Day 6, 12, 18…)에는 그 주 배운 단어 중 5개가 **복습 카드**로 자동 혼합 (간이 스페이스드 리피티션)

## 데이터

- `data/index.js` — 10개 챕터 메타데이터
- `data/ch01.js` — 챕터 1 「일상생활 기초(사람·시간·장소)」 300단어 / Day 1~20 ✅
- 챕터 2~10 (1,800단어)은 미작성. 아래 형식으로 `data/ch02.js` … 를 추가하면 자동 반영됩니다.

```js
window.VOCAB_CHAPTERS = window.VOCAB_CHAPTERS || {};
window.VOCAB_CHAPTERS[2] = {
  id: 2,
  title: "감정과 상태 표현",
  dayTitles: ["소주제1", /* … Day 21~40 에 해당하는 20개 */],
  words: [
    { w:"단어", ipa:"/발음기호/", pos:"명사", kr:"뜻",
      en:"영어 예문", enkr:"예문 해석" },
    // … 정확히 300개, 15개씩 하루치
  ]
};
```

추가 후 `index.html`에 `<script src="data/ch02.js?v=1"></script>` 한 줄을 넣으면 끝입니다.
`day`는 배열 순서로 자동 계산되므로 따로 적지 않습니다.
